# Alpha Lite Releases

Готовые сборки Alpha Lite для Windows.

- [Скачать AlphaLite.exe — версия 1.0.12](https://github.com/fabbiodev/Alpha-Releases/releases/download/lite-v1.0.12/AlphaLite.exe)
- [Все релизы Alpha Lite](https://github.com/fabbiodev/Alpha-Releases/releases?q=lite-v)

Откройте EXE и нажмите Launch. Меню — Insert. Автообновление использует этот публичный репозиторий без GitHub-аккаунта или токена.

В релизах публикуются проверенные EXE без исходных файлов и архивов исходников. Компоненты, шрифт и лицензии встроены; настройки и личные данные пользователей не публикуются.

Стандартные ссылки GitHub Source code архивируют только этот README. Репозиторий разработки остаётся приватным.
