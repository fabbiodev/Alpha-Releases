# Alpha Releases

Готовые сборки Alpha и Alpha Lite для Windows. Скачивайте EXE из раздела [Releases](https://github.com/fabbiodev/Alpha-Releases/releases).

- [Alpha.exe — полная версия](https://github.com/fabbiodev/Alpha-Releases/releases/latest/download/Alpha.exe)
- [Alpha Lite — версии Lite](https://github.com/fabbiodev/Alpha-Releases/releases?q=lite-v)

Откройте EXE и нажмите Launch. Меню: End в полной версии, Insert в Lite. Автообновление работает с этим публичным репозиторием без GitHub-аккаунта или токена.

В релизах публикуются только проверенные EXE. В них нет исходных файлов и архивов исходников. Компоненты, шрифт и лицензии встроены; настройки и личные данные пользователей не публикуются.

Стандартные ссылки GitHub Source code архивируют только этот README, исходников мода там нет. Репозиторий разработки остаётся приватным.
